# Employee Performance AI System

## Overview

Employee Performance AI System is a web-based application designed to help organizations evaluate and monitor employee performance through data-driven insights.

The platform provides a structured way to manage employee records and assess performance indicators.

## Features

* Employee performance tracking
* Employee record management
* Performance evaluation dashboard
* Analytics and reporting
* User-friendly interface

## Technologies Used

* JavaScript
* HTML
* CSS
* Node.js
* Client-Server Architecture
